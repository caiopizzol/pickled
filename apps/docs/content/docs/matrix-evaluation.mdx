---
title: Access evaluation
description: Compare how agents answer with model prior, injected sources, web tools, and MCP tools.
---

Each question runs once per `(agent x access)` pair. That is the whole expansion.

Use this when you want to know which context path carries the right answer:

- **Prior**: no source, no tools. The agent answers from model memory.
- **Injected**: a registered source is placed in the prompt.
- **Web**: the agent must use web search.
- **MCP**: the agent must use the declared MCP server.

## Declare access paths

```yaml
sources:
  readme: ./README.md
  llms: ./llms.txt

agents:
  quick:
    provider: claude-code
    model: claude-haiku-4-5

access:
  prior: { source: none, tools: none }
  injected_llms: { source: llms, tools: none }
  web: { source: none, tools: web }
  docs_mcp:
    source: llms
    tools: mcp
    servers:
      docs:
        url: https://docs.example.com/mcp

questions:
  - id: install
    ask: How do I install my-product?
    agents: [quick]
    access: [prior, injected_llms, web, docs_mcp]
    checks:
      mustMention: ["bunx my-product"]
```

This produces four cells for one agent. Add another agent and it produces eight cells.

## How to read the result

- `prior` fails, `injected_llms` passes: your source carries the answer.
- `injected_llms` fails: the answer is missing or unclear in that source.
- `injected_llms` passes, `web` fails: the source is good, but discovery is weak.
- `web` or `docs_mcp` answers without using a tool: Pickled vetoes the cell to `NO` because the access path was not actually used.

## Plan, cap, and sample

Use `--plan` before a paid run:

```bash
pickled check . --plan
```

Limit or sample larger runs:

```bash
pickled check . --max-cells 10
pickled check . --sample 2 --seed nightly-2026-06-01
```

`--sample` picks cells deterministically per question. The receipt records `expandedCells`, `selectedCells`, and `seed`.
